# Заметки для Claude

## Публикация — без вопросов

Владелец разрешил публиковать **любые** изменения, которые мы вносим, **не спрашивая**.
Сделал и проверил правку → сразу публикуй:

1. Коммит в рабочую ветку сессии, push.
2. Pull request в основную ветку `claude/task-tracker-service-lpv708` и сразу
   squash-merge (заголовок коммита — с номером PR, например `… (#12)`).
3. Дождись GitHub Actions: `deploy.yml` (сайт на GitHub Pages) и, если менялся
   `android/**`, `android.yml` (APK в релизе `android-latest`).
4. Проверь, что на https://borinsobaka-lab.github.io/task-tracker/ новая версия,
   и коротко сообщи владельцу, что опубликовано.

Если рабочая ветка уже была слита, перед новой правкой влей в неё свежую основную
(`git merge origin/claude/task-tracker-service-lpv708`) — без перезаписи истории.

## Что не публикуется само

- **Telegram-бот** (`bot/worker/worker.js`) работает на Cloudflare и обновляется
  вручную: после изменений в нём напомни владельцу вставить новый код в Cloudflare
  (Workers & Pages → воркер → Edit code → Deploy), см. `bot/worker/SETUP.md`.
- **Android-приложение** — оболочка над сайтом: изменения сайта видны в нём сразу,
  новый APK нужен только при изменениях в `android/`.

## Проверки перед публикацией

- `npm run build` (проверка типов + сборка).
- e2e: `PW_CHROMIUM_PATH=/opt/pw-browsers/chromium npx playwright test`.
  Тесты «таймлайн календаря…» и «живая публичная ссылка на таймлайн…» падают и на
  основной ветке — это давняя проблема, не связанная с текущими правками.
- Тесты бота: `node bot/worker/test.mjs`.
